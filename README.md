# Project: Data Dig - Analysis of World Countries

This is my Khan Academy Advanced SQL project.

### Dataset
Top countries by population - includes population, fertility_rate, median_age, density, net_migrants, etc.

### Questions Explored
As suggested by the project:
1.  **AVG, MAX, MIN:** What is the average world country population? What is the smallest and largest?
2.  **HAVING:** Which fertility rates represent over 100M people combined?
3.  **CASE:** How can we group countries by age demographics that don't exist in the table?
4.  **AND/OR:** Filter countries with high immigration but low growth, or very dense / very old populations.

### How to Run
Copy `queries.sql` into Khan Academy SQL editor or any SQLite environment.

### Skills Demonstrated
SQL, Aggregate Functions, GROUP BY, HAVING, CASE WHEN, AND/OR logic
